## 🚀 실행 방법

아래 명령어를 순서대로 실행하면 프로젝트를 로컬에서 실행할 수 있습니다.

### 1. 저장소 클론

```bash
git clone https://github.com/yooaknow/streamlit-quiz-project.git
```

### 2. 프로젝트 폴더로 이동

```bash
cd streamlit-quiz-project
```

### 3. 필요한 패키지 설치

```bash
python -m pip install -r requirements.txt
```

### 4. Streamlit 앱 실행

```bash
python -m streamlit run app.py
```

### 5. 브라우저에서 확인

실행 후 터미널에 표시되는 URL(보통 [http://localhost:8501)을](http://localhost:8501%29을) 브라우저에서 열면 됩니다.
